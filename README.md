# SMASH V16.0 · 羽球生涯

**从第一分，到世界第一。**

SMASH 是一款女子单打羽毛球职业生涯模拟游戏。选择巡回赛中的一名球员，或创建自定义球员，从赛场新人逐步成长为世界顶尖选手。规划赛程、培养技术风格、研究对手、制定战术，在漫长的职业生涯中争夺冠军与荣誉。

## 开始游戏

- 在线游玩：在浏览器中打开游戏网页，首次进入需要联网。推荐使用 Chrome、Edge 或 Firefox。
- 本地游玩：完整解压游戏文件，在解压目录打开终端，运行 `python -m http.server 8000`，再在浏览器访问 `http://localhost:8000`（需要安装 Python）。请勿直接双击 `index.html`。
- 可选择现有球员，也可自定义姓名、年龄、国籍、身高、持拍手、初始能力及潜力。
- 游戏支持电脑和手机浏览器，生涯进度自动保存在当前浏览器中。

## 巡回赛与排名

巡回赛包括 S100、S300、S500、S750、S1000，以及世界锦标赛和年终总决赛。不同赛事具有不同的参赛门槛、签表规模及积分奖励。

- 报名成功不等于直接进入正赛。正式审核可能产生直接入围、资格赛入围或未入围三种结果，请留意消息中心。
- S300 最多接纳 88 名球员，其中 24 人直接入围正赛、64 人参加资格赛，最多经过三轮争夺 8 个正赛席位。报名人数较少时，资格赛规模相应调整。
- 最近 12 周获得 S100 冠军或亚军的球员，在 S300 报名超额时可竞争最多 4 个资格赛优先名额。
- 世界排名根据最近 52 周内成绩最好的 10 站赛事积分计算；赛季积分榜采用成绩最好的 14 站巡回赛积分，其中最多计入 3 站 S100。
- 合理安排参赛与休赛，避免同期赛事冲突及过度疲劳。比赛负荷、伤病与年龄都会影响竞技表现。

## 比赛规则

- 采用三局两胜、每局 15 分制。14 平后须领先 2 分获胜，21 分封顶。
- 每局领先方达到 8 分时进入局内间歇；局间安排休息，球员按比赛规则换边。
- 每个回合均计分，胜方获得下一分发球权。女单比赛采用正手高远发球。
- 比赛表现受球员技术、身体条件、持拍手、竞技状态及战术共同影响。高排名并不保证获胜。
- 小组赛结束后显示胜负，淘汰赛结束后显示晋级或淘汰，决赛获胜显示夺冠。

## 备战与临场战术

赛前可查看双方历史交锋、近期战绩、发接发及长短回合表现，结合制胜球落点和场区占位报告制定战术。可选择自适应、均衡、主动进攻、拉吊调动、防守反击、网前压制、消耗对手或稳健控制，并调整落点偏好、击球风险、回合节奏及回位倾向。

比赛中可随时暂停并调整战术，新的战术从下一分起生效。场上局势变化时，应根据实际表现灵活调整，而非始终采用同一种打法。

## 观赛与技术统计

- 可调整镜头、播放速度与分间休息设置；通过「回放」查看最近三分的完整画面。
- 技术统计采用双方对比形式，包含制胜分、失误、发接发胜率、长短回合表现及移动距离等指标。
- 制胜球落点热力图展示直接得分的落点，场区占位热力图展示球员在各场区的停留分布。历史报告随生涯比赛逐步积累。
- 在比赛的「更多」菜单中，可模拟至下一间歇、本场比赛结束或本站赛事结束。快速结算适合推进赛程，完整观赛适合分析技术与战术表现。
- 整站模拟遇到需要确认的报名事项或结果时会暂停。整赛季模拟可在生涯设置中开启。

## 专项训练与球员成长

在「能力发展」中选择 2–3 项专项训练，或采用均衡训练。高亮属性即当前重点发展方向。

| 训练专项 | 发展方向 |
| --- | --- |
| 主动进攻 | 后场下压、连续突击 |
| 拉吊调动 | 落点控制、前后场调动 |
| 防守反击 | 接杀、被动回球与反击 |
| 网前压制 | 网前争夺、接发球 |
| 步法与爆发 | 启动、变向及移动效率 |
| 耐力与身体维护 | 长回合相持、维持竞技能力 |
| 比赛心理与决策 | 预判、抗压及临场判断 |

训练按周结算，计划持续生效，直到主动修改。两项训练更集中，三项训练更全面。年轻球员可定向发展能力，成熟球员可维持优势，衰退阶段则可延缓重点属性的自然下降。成长仍受年龄、潜力、比赛负荷及伤病影响。

## 存档与升级

生涯进度自动保存在当前浏览器中，也可通过生涯设置导出、导入存档。建议定期导出备份，尤其是在更换设备、浏览器或升级游戏前。V16.0 支持此前兼容的女单生涯存档，无需重新开档。升级时请完整替换游戏文件，再打开游戏或导入备份。
